# @tinyhttp/response

[![npm (scoped)][npm-badge]](https://npmjs.com/package/@tinyhttp/response) [![npm][dl-badge]](https://npmjs.com/package/@tinyhttp/response) [![][web-badge]](https://tinyhttp.v1rtl.site/mw/res)

Response extensions for tinyhttp collected in one package. This module itself depends on other modules, such as [`@tinyhttp/send`](/packages/send).

## Install

```sh
pnpm i @tinyhttp/response
```
