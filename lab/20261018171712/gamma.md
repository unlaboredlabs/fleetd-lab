fleetd's merge train is the only thing that merges pull requests in this testbed. `main` requires two checks before any merge: the `ci` check, which fails whenever a file named `FAIL` exists at the repo root, and the `fleetd/train` commit status, which only the train sets. `main` also accepts squash merges only. Because the train alone posts `fleetd/train`, a pull request cannot land on `main` through the normal merge path until the train has approved it, so authors open pull requests and leave the merge to the train.
