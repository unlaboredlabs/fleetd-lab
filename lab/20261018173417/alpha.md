fleetd's merge train is the only thing that merges pull requests into `main` in this repo. `main` requires both the `ci` check and the `fleetd/train` commit status before a merge is allowed, and it accepts squash merges only. The train is the sole writer of the `fleetd/train` status, so a pull request can land only after the train has set it. CI passes unless a file named `FAIL` exists at the repo root, so a change that adds that file will fail the `ci` check and cannot land.
