fleetd's merge train is the only thing that merges pull requests into main in this repository. Main requires the ci check to pass and the fleetd/train commit status to be posted before a change can land, and only squash merges are allowed, so the train is the one that merges a branch once those conditions hold. The ci check fails whenever a file named FAIL exists at the repository root, which gives the train a simple way to block a change.
