fleetd's merge train is the only thing that merges pull requests into the slot's main branch in the fleetd-lab repository. A slot's main requires two things before a change can land: the ci check must pass, and the fleetd/train commit status must be posted, and only squash merges are allowed. Contributors open a pull request from their task branch and leave it alone; the train picks it up, confirms the required checks, squash merges it, and posts the fleetd/train status that branch protection needs. Because the train is the sole path to main, a writer never merges or posts that status by hand.
