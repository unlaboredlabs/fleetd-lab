fleetd's merge train is the only thing that merges pull requests into the slot's main branch in this repository. Main requires the ci check to pass and the fleetd/train commit status to be posted before a change can land, and only squash merges are allowed, so the train is the one that merges a task branch once those conditions hold. Contributors open a pull request from their task branch and leave it alone; the train confirms the required checks, squash merges the change, and posts the fleetd/train status that branch protection needs. Because the train is the sole path to main, a writer never merges or posts that status by hand.
