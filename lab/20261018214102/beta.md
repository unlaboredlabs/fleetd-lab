fleetd's merge train is the only path that merges task pull requests into main in this repository. When a task branch is ready, fleetd spawns tier reviews on the pull request, then rebases the branch onto the current main and waits for CI to report green. Only the train performs the merge, so writers never merge their own pull requests or post the fleetd/train commit status themselves. If the rebase hits a conflict or CI turns red, the train does not merge; the pull request goes back to the writer to fix and push again.
