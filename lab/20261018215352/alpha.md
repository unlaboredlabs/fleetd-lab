fleetd's merge train is the only path that merges pull requests into main in this repository. When a task branch such as fleetd/T1-write-alpha-md is ready, the train checks that the branch rebases cleanly onto main and that the required ci check passes, and only then squash-merges the pull request and posts the fleetd/train commit status that main's branch protection requires. Contributors therefore never merge a pull request or post that status themselves. If the rebase conflicts or CI fails, the train does not merge; it hands the branch back to its writer.
