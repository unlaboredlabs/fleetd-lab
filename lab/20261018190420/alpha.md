fleetd's merge train is the only thing that merges pull requests into main in this repository. It takes open task branches, such as fleetd/T1-write-alpha-md, and merges each one with a squash merge once the required checks pass. Those checks are the ci status check and the fleetd/train commit status, which the train posts itself and which the branch protection on main requires. Contributors open the pull request and leave the merge to the train, so they never merge or post the fleetd/train status by hand. Per the README, CI fails whenever a file named FAIL exists at the repository root.
