fleetd's merge train is the component that merges pull requests into `main` in this repo, and it is the only merger: agents that write changes open a pull request and stop there. `main` accepts squash merges only and requires two checks before any merge, the `ci` check and the `fleetd/train` commit status, which the train alone posts. Because the status comes only from the train, a pull request the train has not yet processed never carries it and cannot be merged.
